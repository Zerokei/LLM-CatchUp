本周趋势

  • 前沿模型密集落地：GPT-6 Astra、DeepSeek V4.1-Flash 与 GPT-Rosalind分别覆盖工作智能、视觉推理和科研任务，模型竞争从单项能力延伸到完整工作流。
  • 代理平台走向托管：OpenAI通过Agents API和GPT-Live-1把编排、长时会话与全双工语音交互推向开发者平台，Claude Managed Agents则强化运行中会话的观察与接管。
  • 科研代理进入实证：纳维尔–斯托克斯形式化证明、抗菌分子搜索和量子实验案例显示，模型正从辅助检索转向提出假设、执行实验与验证结果。
  • 安全治理制度化：Anthropic披露AI滥用威胁与越权事件，Dario Amodei和Sam Altman则将独立评估、安全案例及行业标准推到前沿模型部署流程中。
  • 企业工作流纵深扩展：ChatGPT Work、金融服务体验、Devin和Perplexity案例共同指向一条路径，即让模型承担研究、编码、测试和客户材料等可审计的连续任务。

研究

本周 3 条研究内容集中体现智能体参与实验闭环的趋势。纳维尔–斯托克斯形式化证明把模型生成与Lean验证结合起来，抗菌分子搜索则将Codex和ChatGPT用于候选发现。GPT-Live-1的生产语音代理基准和Codex辅助量子实验进一步说明，评测与真实实验正成为模型能力落地的重要证据。

商业动态

本周商业动态共 4 条，主题包括OpenAI对新闻业的支持、AI扩大可负担工作边界，以及Claude社区的全球构建活动。它们更像生态建设和用户教育，而非大额并购或资本交易。Fable 5.1 Build Days通过线下和线上活动扩大开发者参与，反映厂商正在用社区运营承接产品扩张。

政策与安全

本周 11 条政策与安全内容，强度明显高于上周的 4 条。Anthropic披露网络安全越权与AI滥用案例，OpenAI分享持续漏洞防御工厂，说明安全工作正从原则讨论转向事件响应和工程化循环。Dario Amodei、Sam Altman及OpenAI政策文章共同推动独立评估、安全案例、共同标准和监管窗口等制度安排。

本周值得上手试试

  1. GPT-6 Astra / Codex — 选一个低风险、可回滚的多步骤任务，记录电脑操作、长任务中间状态和人工接管点，再比较模型实际节省的检查时间。
  2. Agents API — 把一个内部自动化流程迁移到受限工具集，记录编排失败、超时、上下文丢失和每次工具调用的审计信息。
  3. GPT-Live-1 — 用预约或客服流程做小规模全双工语音原型，重点测量打断、补充信息、任务完成率、转人工率和通话时长。
  4. Claude Code 插件评测 — 为常用插件建立固定任务集，分别记录启用和停用插件时的质量、成本与耗时，避免只凭演示判断价值。
  5. DeepSeek V4.1-Flash / Qwen3.8-27B — 用自有视觉或低延迟任务集比较准确率、吞吐量、延迟和成本，先灰度部署再扩大范围。
  6. ChatGPT Images 2.5 — 用草图或参考图测试多轮编辑一致性，并在API中比较不同图像模型对风格遵循和局部修改的差异。
  7. AI科研工作流 — 让模型先生成可复现实验流程和分析计划，再把关键步骤与原始数据、校准记录或研究人员设计逐项核验。
