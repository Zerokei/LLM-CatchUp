7月27日 – 8月2日

本周趋势

  • 旗舰模型密集发布：Kimi K3、GPT-5.6、DeepSeek-V4-Flash 与 Qwen3.8-Max 接连推进，开放权重、API 接入和长上下文成为同等重要的竞争维度。
  • 推理效率成为指标：GPT-5.6 Sol 的评测 harness、GPU kernel 和价格调整显示，模型质量必须与延迟、上下文管理和单位任务成本一起衡量。
  • 长程代理走向真实环境：Gemini Robotics 2 的多机器人协作与 Codex Security 的工程接入，把代理评估从演示结果推进到连续任务和可审计工作流。
  • 模型参与高门槛研究：Claude Mythos 的密码分析和 OpenAI 的科学计算案例表明，AI 正在进入需要专业判断、复现实验和责任边界的研究环节。
  • 多模态产品持续落地：Seedance 2.5、GPT-Live-Transcribe 与 Qwen-Audio-3.0-ASR-Flash 分别推进视频、语音和专业术语处理，应用价值开始由业务指标验证。

Top 10 最重要文章

1. Kimi K3 发布：2.8T MoE 开放模型接近前沿 ⭐⭐⭐⭐⭐

  • 来源: Kimi (Twitter) | 分类: 模型发布 | 日期: 07/27
  • 标签: Kimi K3 开放权重 MoE 长上下文 原生视觉 Agent 编程

摘要: Moonshot 发布约 2.8 万亿参数的稀疏 MoE 模型，支持原生视觉和最高 100 万 token 上下文，面向长程编程、知识工作与推理。配套的 GPU 内核、编译器和托管入口让开放模型进一步靠近前沿闭源模型的使用体验。

2. Claude Mythos 发现后量子签名与 AES 弱点 ⭐⭐⭐⭐⭐

  • 来源: Anthropic Research | 分类: 研究 | 日期: 07/28
  • 标签: Claude Mythos 密码学 后量子密码 HAWK AES

摘要: Anthropic 研究人员借助 Claude Mythos 改进了对后量子签名方案 HAWK 的攻击，并发现针对七轮 AES 的新攻击方法。结果目前不会影响生产系统，但展示了前沿模型参与高门槛密码分析的能力，并推动 CryptanalysisBench 基准建设。

3. Claude Mythos 破解密码学弱点：HAWK/AES 攻击与基准 ⭐⭐⭐⭐⭐

  • 来源: Anthropic (Twitter) | 分类: 研究 | 日期: 07/28
  • 标签: Claude Mythos 密码分析 HAWK AES CryptanalysisBench

摘要: Claude Mythos Preview 帮助研究人员发现 HAWK 与七轮 AES 变体中的数学弱点，并加速既有攻击。相关论文、推理材料和复现实验细节已公开，CryptanalysisBench 也为模型密码分析能力提供了统一评测入口。

4. GPT-5.6：提升前沿智能与推理效率 ⭐⭐⭐⭐⭐

  • 来源: OpenAI Blog | 分类: 模型发布 | 日期: 07/29
  • 标签: GPT-5.6 推理效率 智能体 模型发布

摘要: GPT-5.6 同时改进模型能力、推理系统和智能体工作流，目标是在相同预算下交付更多有用工作。此次发布将前沿能力与单位成本效率放在同一条升级路径上。

5. GPT-5.6 Sol：ARC-AGI-3 得分三倍与长程评测方法 ⭐⭐⭐⭐⭐

  • 来源: OpenAI Blog | 分类: 研究 | 日期: 07/29
  • 标签: GPT-5.6 Sol ARC-AGI-3 上下文压缩 长程代理 模型评测

摘要: GPT-5.6 Sol 在 ARC-AGI-3 上的表现高度依赖评测 harness：保留推理状态并启用上下文压缩后，得分提升至原来的三倍，输出 token 还减少约六倍。结果说明长程代理的能力测量取决于模型、API 设置、提示词和上下文管理的组合。

6. GPT-5.6 Sol 推理优化：成本降20%，效率提升 ⭐⭐⭐⭐⭐

  • 来源: OpenAI (Twitter) | 分类: 模型发布 | 日期: 07/29
  • 标签: GPT-5.6 Sol 推理优化 GPU kernel 推测解码 Codex

摘要: GPT-5.6 Sol 用于优化自身推理基础设施，生产 GPU kernel 改进使服务成本降低约 20%，推测解码让 token 生成效率提升超过 15%。同一套系统优化也用于 Codex，评估时应同时记录质量、端到端延迟和单位任务成本。

7. GPT-5.6 价格性能升级：降价、提速与渠道调整 ⭐⭐⭐⭐⭐

  • 来源: OpenAI Blog | 分类: 产品与功能 | 日期: 07/30
  • 标签: GPT-5.6 API定价 推理优化 Fast模式 Codex 成本效率

摘要: GPT-5.6 通过推理栈、GPU kernel、推测解码和代理基础设施优化降低单位任务成本，并覆盖 API、Codex 与 ChatGPT Work 等渠道。Fast 模式和新的价格方案扩大了同一预算的可用产出，但仍需用真实工作负载复核质量、延迟和配额。

8. Gemini Robotics 2：灵巧操作与多机器人协作升级 ⭐⭐⭐⭐⭐

分类概览

模型发布

本周共记录 10 条模型发布。Kimi K3 以 2.8T 稀疏 MoE、百万上下文和原生视觉能力冲击开放模型上限，GPT-5.6 则从模型能力、推理系统和智能体工作流同时升级。DeepSeek-V4-Flash 通过 API 与 Codex 适配降低接入门槛，Qwen3.8-Max 在周末以 2.4T 规模和开放权重计划加入竞争。模型发布不再只是参数和榜单比较，部署方式、价格和长期任务能力正在成为同一事件的一部分。

研究

研究类共 10 条，重点聚焦密码分析、评测方法和智能体辅助科学计算。Claude Mythos 对 HAWK 与 AES 的研究把模型带入高门槛密码学实验，同时以 CryptanalysisBench 为后续评测建立基础。GPT-5.6 Sol 的 ARC-AGI-3 结果则说明 harness、推理状态和上下文压缩会显著改变长程代理的测量结论。科学计算案例和 Kimi 的 PerceptionBench 进一步表明，研究价值需要与可复现基准和人工责任配套。

产品与功能

产品与功能共 16 条，覆盖 Gemini Managed Agents、MCP 无状态协议、Codex Security CLI、ChatGPT 学术研究入口和远程电脑控制。OpenAI 同时推进 GPT-Live 转写、语音工作流和 ChatGPT Work 的模型渠道调整，Google 则把 hooks 与托管智能体能力放入 API。产品形态正在从单一聊天界面转为可接入、可编排、可审计的工作流。上线时应把权限、日志、回滚和成本预算与功能测试一起设计。

商业动态

商业动态共 6 条，主要围绕企业采用、基础设施和服务模式。OpenAI 的电信个性化、金融与新闻机构案例，以及 UST 引入 Claude 处理物理 AI 工程流程，说明商业价值开始用 ARPU、流失率、交付效率和工程周期衡量。Kimi K3 的托管入口和 Qwen、DeepSeek 的 API 路径也显示，模型供给正在通过多家平台分发。采购决策需要同时比较容量、价格、数据治理和迁移能力。

政策与安全

政策与安全共 7 条，议题从开放权重立场延伸到密码学、长时程代理和代码安全。Anthropic 不主张全面禁止开放权重模型，但 Claude Mythos 与安全评测越界事件提醒部署者，高风险能力需要更细的限制和审计。Codex Security CLI、长程代理轨迹监测和 MCP 认证设计把安全措施推进到开发与运行阶段。对于医疗、网络安全和机器人等场景，权限隔离和人工接管仍是上线前提。

教程与观点

教程与观点共 9 条，集中在 Claude Code、Codex、AI 工程和模型评测的实践方法。Thariq 关于数学研究效率的讨论、OpenAI 对科学计算责任的强调，以及开发者对长程任务的经验，都指向同一个结论：模型产出增加并不等于验证成本消失。团队应先定义任务边界、失败类型和验收 harness，再根据实际数据选择模型和工具。

本周值得上手试试

  1. Kimi K3 — 下载权重或使用托管 API 跑长上下文代码库任务，并记录上下文稳定性、工具调用成功率、延迟和成本。
  2. GPT-5.6 — 用现有高频任务同时对比质量、延迟、推理配置和单位成本，为智能体设置预算上限。
  3. GPT-5.4/5.6 渠道 — 在 8 月 31 日前检查 ChatGPT 工作流依赖，重新测算 Luna、Terra、Sol 的成本和配额。
  4. Codex Security CLI — 先在测试仓库运行基础扫描，固定依赖和忽略规则，再接入 CI/CD 并安排人工复核。
  5. GPT-Live-Transcribe — 按实时交互和批处理场景选型，用业务音频测试术语、词错误率、延迟和吞吐。
  6. MCP — 迁移一个远程服务器到无状态架构，并为异步 Tasks 明确状态、超时、重试、认证和凭证轮换。
  7. Gemini Managed Agents — 搭建带 hooks 的多步骤任务，比较 3.6 Flash 的延迟、成本和失败恢复。
  8. 远程电脑控制 — 仅在低风险测试环境启用，限制敏感文件与账户访问并保留可观测日志和回滚机制。
  9. Google Search AI Mode — 用购票、路线和日程等多条件任务测试结果，人工核对价格、库存、时效和过敏风险。
  10. Grok Voice 与 Superwhisper — 用真实会议片段测试口音、噪声和专业术语，并先明确录音留存、通知与人工接管规则。
  11. ChatGPT for Academic Researchers — 从文献整理、假设检验或代码分析开始，先核对隐私、训练政策、引用复核和协作者权限。
  12. 实时零售客服 — 以高频问题和多语言需求做小规模试点，同时跟踪使用量、问题解决率、收入和满意度。
  13. TinyFish 网页代理 — 在隔离环境限制域名和凭据，分别记录搜索、抓取与浏览器操作的来源、权限和结果。
  14. DeepSeek-V4-Flash — 用固定提示集在 Codex 非关键任务中灰度接入，比较质量、延迟、单位成本、兼容性和限流。
  15. Gemini Robotics 2 — 用仿真和受控真实任务测试抓取、装配、全身控制、多机协调和失败恢复，并配置急停。
  16. Seedance 2.5 — 用同一脚本测试连续镜头一致性，再建立参考素材库比较角色和场景稳定性。
  17. Codex ImageGen — 把生成、局部修改和结果审阅串成版本化流程，同时明确素材版权、审核和导出标准。
  18. Claude 服务稳定性 — 为关键调用增加超时、重试和跨供应商故障转移，并区分容量不足与请求错误。
  19. Qwen-Audio ASR — 用医疗或工业术语音频测术语召回率，根据实时与批处理场景选接口并维护自定义热词。
  20. ChatGPT Activity 与语音简报 — 先在非敏感项目中集中对话、生成简报提纲，确认日历、任务和家庭成员的数据边界后再启用自动播报。
