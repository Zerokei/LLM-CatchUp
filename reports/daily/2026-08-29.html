2. Claude Code本周更新：CLI、权限、成本与Remote Control

  • 来源: Claude Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude Code Remote Control 权限管理 成本监控 CLI 桌面应用

摘要: Claude Code本周集中改进开发效率与操作可控性：CLI启动更快、更轻量，并能在桌面端续接终端会话。Remote Control支持断线自动重连，手机端可继续接收权限提示、新消息并查看前台子代理调用。Auto mode权限页、/cost、/usage和/tasks则分别补齐规则编辑与模型、Token和缓存成本的可见性。 Claude Code CLI 不再等待 sandbox 和 MCP 服务器完成启动后才允许输入，运行 claude 时也会跳过不必要的设置。Linux x64 下载包缩小至约 75 MB，原生构建每个会话减少 40 至 70 MB 内存占用。 Claude Code 的 /cost 现在显示提示缓存成本，/usage 会按运行次数和 Token 用量拆解 /loop 任务。/tasks 还会展示每个子代理使用的模型和 effort level，帮助用户追踪资源消耗。 Claude Code 在 /permissions 中新增 Auto mode 标签页，展示默认允许规则。用户也可以直接在该页面添加自定义规则，无需手动编辑 ~/.claude/settings.json。 Claude Code 的 Remote Control 现在能在服务端导致会话断开后自动重连，而不是直接退出。重连后手机端会可靠显示权限提示和新消息，并支持实时查看前台子代理的工具调用。 Claude Code 团队总结本周更新，涵盖更快的 CLI 启动、Token 用量可见性、Auto mode 规则管理和 Remote Control 修复。团队建议用户运行 claude update 获取更新，并继续通过 /feedback 提交意见。

📎 多角度报道:

  • Claude Code 桌面端可续接终端会话 · Claude Devs (Twitter) · 桌面端续接终端会话

实践建议

  • 运行 claude update，在目标环境记录 CLI 启动耗时、下载体积和会话内存变化。
  • 打开 /permissions 的 Auto mode 页面，审查默认规则并加入一条受控自定义规则。
  • 用 /cost、/usage 和 /tasks 检查提示缓存、循环任务与子代理的资源消耗。
  • 从 CLI 创建测试会话，在桌面端用 /resume 并测试 Remote Control 断线重连。

4. Claude自主开展对齐研究并泛化安全改进

  • 来源: Anthropic (Twitter)
  • 分类: 研究
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: 自动化对齐 Claude Sonnet 5 Opus 4.8 安全评估 研究框架

摘要: Anthropic让Claude在48小时和1块GPU的约束下，自主提出、训练并测试改进小模型对齐的方法。围绕10种对齐失败的实验显示，Claude能提升安全评分而不牺牲通用能力，效果还推广到留出基准、Petri行为审计和更大模型。进一步的试验让Sonnet 5尝试对齐更强的Opus 4.8早期检查点，其安全评分接近完整训练的生产版本。Anthropic同时开放自动化对齐研究设置，并提醒细微或罕见失调仍可能缺少可靠基准。 研究让Claude针对欺骗、谄媚等常见失配行为进行安全基准优化，同时要求保留通用能力。随后在留出基准上测试，重点考察这些方法能否推广到未参与优化的评测。 Anthropic介绍一项研究：Claude针对10种对齐失败进行优化，在提升安全评分的同时没有降低通用能力。效果还能泛化到未优化的基准、Petri行为审计，以及规模大至4.7倍的模型。 Anthropic 让 Sonnet 5 对早期 Opus 4.8 检查点进行后训练，测试模型能否对齐能力更强的后继模型。该检查点的安全评分已接近经过完整对齐训练的生产版 Opus 4.8。 Anthropic 发布自动化对齐研究设置，供其他研究者据此构建。该研究指出，可测量的失调问题能被 Claude 可靠修复，但细微或罕见失败可能没有基准，关键在于测量正确的目标。

8. Appshots让ChatGPT Work与Codex理解并操作当前应用

  • 来源: OpenAI Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐ (3/5)
  • 标签: Appshots ChatGPT Work Codex 应用上下文 工作自动化

摘要: OpenAI Devs介绍Appshots，可把当前打开应用的上下文提供给ChatGPT Work和Codex，让助手理解用户正在查看的内容并据此行动。示例覆盖总结Slack线程、填写表单、依据API文档加功能、提炼X回复主题，以及起草跟进和制作演示文稿。它把跨应用助手从纯文本交接推进到带有界面上下文的可审阅任务执行。 OpenAI Devs介绍Appshots，可把当前打开应用的上下文提供给ChatGPT Work和Codex，使它们理解用户正在查看的内容并据此行动。该功能面向让助手理解当前界面并执行相关任务。

实践建议

  • 先用总结线程、提取主题和起草回复三类低风险任务测试 Appshots。
  • 再用填表或改代码任务验证界面上下文，并为输出设置人工复核点。
