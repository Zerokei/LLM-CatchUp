3. OpenAI推出托管式Agents API

  • 来源: OpenAI Blog
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: 智能体 Agents API 云服务 工具调用 Codex
