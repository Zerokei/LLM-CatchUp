1. Claude Opus 5 发布：代理能力、网络安全与 Claude Code 全面升级

  • 分类: 模型发布

2. ChatGPT Work agent 支持登录后持续使用网站

  • 来源: OpenAI Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: ChatGPT Work 浏览器代理 登录状态 云端浏览器

摘要: ChatGPT Work agent 现在可以操作需要登录的网站。用户接管云端浏览器完成登录后，代理会继续执行任务，并在不同会话间保留登录状态，因此无需重复认证。

实践建议

  • 先在低风险测试账户中验证代理登录、会话持久化和退出机制。
  • 为涉及敏感网站的任务设置人工接管、域名白名单和凭据隔离。

4. Grok STT 语音转文字服务上线 OpenRouter

  • 来源: xAI (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐ (3/5)
  • 标签: Grok STT OpenRouter 语音转文字 说话人分离

摘要: Grok STT 已在 OpenRouter 上线，支持 25 种语言的语音转文字。服务提供逐词时间戳和说话人分离，价格为每小时音频 0.10 美元。

实践建议

  • 用多语言和多人对话样本测试识别准确率、时间戳质量与说话人分离效果。
  • 将 Grok STT 与现有转写服务做成本和延迟对比，再决定是否接入生产流程。

6. Grok Build 集成 Exa 代理式网页搜索

  • 来源: xAI (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐ (3/5)
  • 标签: Grok Build Exa 网页搜索 代理工具

摘要: Grok Build 现在可以安装 Exa 插件，用于在构建代理中调用网页搜索。Exa 将其定位为面向代理的快速、高准确度搜索服务。

实践建议

  • 在 Grok Build 中安装 Exa 插件，比较其检索结果与现有搜索工具的准确率。
  • 为代理搜索增加来源引用、域名限制和失败回退策略。
