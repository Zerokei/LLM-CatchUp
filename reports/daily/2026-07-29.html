  • 来源: OpenAI (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Codex Security 代码安全 开源工具 CI/CD npm 安全扫描

摘要: OpenAI 开源 Codex Security CLI，可扫描代码库、跨运行追踪安全发现、验证修复，并把安全检查接入 CI/CD。工具提供 npm、npx、源码和文档入口，降低了从试用到工程集成的门槛。它仍处于早期版本，团队应先在非生产仓库建立发现基线，再结合人工复核、权限控制和固定版本逐步纳入流水线。 Codex Security CLI 可通过 npm 全局安装，也可以使用 npx 直接运行并查看帮助信息。该安装入口降低了开发者试用开源代码安全工具的门槛。 OpenAI 补充公布了 Codex Security CLI 的源码和文档地址。开发者可以据此检查工具实现、了解使用方式，并将安全扫描流程纳入现有工程规范。

实践建议

  • 先用 npx 在测试仓库运行帮助命令和基础扫描，建立发现基线。
  • 阅读文档后为项目选择扫描范围和忽略规则，再把安全检查接入 CI/CD。
  • 团队确认版本后固定 npm 依赖，并为高风险发现设置人工复核。
  • 接入生产流水线前审查源码、权限需求和发现处理流程。

4. GPT-Live-Transcribe 与 GPT-Transcribe：实时/异步转写升级

  • 来源: OpenAI Devs (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: GPT-Live-Transcribe GPT-Transcribe 语音模型 上下文增强 多语种 OpenAI API 语音评测

摘要: OpenAI API 推出 GPT-Live-Transcribe 与 GPT-Transcribe，分别面向低延迟实时转写和已完成音频、批处理场景。两款模型支持自由文本上下文、关键词、预期语言和此前转写内容，以改善口音、数字、专业术语和噪声环境下的识别。官方多语种评测显示，两者在语义准确率和错误率上均优于相应 Whisper 基线，接入时仍应使用业务音频做端到端验证。 GPT-Live-Transcribe 可接收自由文本上下文、关键词、预期语言和此前转写内容，以提升专名和领域术语的识别效果。官方评测显示，加入自由文本上下文后语义准确率从 38.5% 提升至 44.6%，并在多语种错误率测试中优于 GPT-Realtime-Whisper-1。 GPT-Transcribe 在上下文感知语音识别评测中，加入自由文本上下文后语义准确率从 41.6% 提升至 45.2%。在 22 种语言的 Common Voice 测试和九种语言的真实录音测试中，其错误率均明显低于 Whisper-1。 OpenAI Devs 分享了新转写能力的 API 使用指南，帮助开发者接入实时和异步音频转写。指南页面是该线程的实现入口，具体参数与调用方式应以文档为准。

实践建议

  • 根据延迟和吞吐需求，在实时交互与批处理场景分别选型。
  • 为产品维护领域词表、专名和语言提示，并随请求传入。
  • 用业务音频对准确率、延迟和成本做端到端基准测试，分别监测语义准确率与词错误率。
  • 将自由文本上下文作为可配置项接入多语言转写流水线。
