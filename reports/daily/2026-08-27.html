1. Qwen3.8-Flash上线：百万上下文与多平台调用

  • 来源: Qwen (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: Qwen3.8-Flash 百万上下文 QwenCloud OpenRouter 多模态 API定价

摘要: Qwen3.8-Flash 已在 OpenRouter 和 QwenCloud 上线，面向代码助手、智能体、多模态推理、文档分析和长视频理解等场景。模型原生支持 262K 上下文并可扩展至 1M，QwenCloud 给出的输入价格为每百万 token 0.15 美元，缓存命中仅 0.016 美元。开发者可以先用统一 API 验证长上下文和工具调用效果，再结合低价与缓存能力评估生产部署。

📎 多角度报道:

  • Qwen3.8-Flash上线QwenCloud：百万上下文低价可用 · Qwen (Twitter) · QwenCloud上线与定价

实践建议

  • 用长文档或代码库基准测试 262K 上下文下的准确率、延迟和成本。
  • 通过 OpenRouter 与 QwenCloud 对比代码库分析、文档问答和长视频任务。
  • 对重复系统提示和稳定上下文启用缓存命中，比较优化前后的请求成本。

2. Gemini 3.5 Transcribe正式发布

  • 来源: Google DeepMind (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: Gemini 3.5 Transcribe 语音转文本 Google AI

摘要: Google DeepMind发布Gemini 3.5 Transcribe，将其定位为面向精准、智能转写的最新语音转文本模型。相关能力可在macOS版Gemini应用和Android版Gboard中试用，也可通过Google AI Studio和Antigravity开始构建。 Gemini 3.5 Transcribe提升了对复杂电话号码、邮编和订单号的识别能力，即使在嘈杂环境中也能更准确转写。它还能去除口头填充词、自动格式化文本、识别自定义词汇，并支持自动检测和转写85种以上语言。

实践建议

  • 先用Gemini 3.5 Transcribe处理一段典型业务录音，记录准确率、延迟和格式化效果。
  • 通过Google AI Studio构建一个小型转写原型，再评估其多语言和专有词汇表现。

4. Cowork 侧栏浏览器可代办网页任务

  • 来源: Claude (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Cowork 网页智能体 表单填写 任务自动化

摘要: Claude 在 Cowork 中提供内置浏览器，遇到网页任务时会在侧栏打开浏览器。Claude 可以代用户导航网站、填写表单并完成流程，把多步网页操作纳入任务执行。 Cowork 将浏览器直接集成到桌面应用中，无需额外安装，并与用户自己的浏览器及登录状态保持隔离。该功能将在一周内向所有付费计划用户逐步推送。 Claude in Chrome 现已面向所有付费计划正式开放，用户可以在自己已经登录的浏览器环境中使用 Claude。此前已在使用该功能的用户仍会继续将其作为默认浏览器代理。

实践建议

  • 先用 Cowork 处理可回滚的网页流程，例如整理资料或填写非提交型表单。
  • 对最终提交、发送或产生外部影响的动作保留人工复核，逐步扩大自动化范围。

5. Claude Code 自动起草可审阅反馈

  • 来源: Claude Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude Code 反馈草稿 错误处理 开发者体验 配置

摘要: Claude Code 会在任务失败、发现自身错误或收到用户报错时自动起草反馈报告，开发者可以在发送前审阅、修改和批准。反馈草稿会保留复现步骤与上下文整理的便利，同时把最终发送权留给用户。相关工具更新还支持通过「/config」关闭或调整行为，适合纳入团队故障处理流程。 Claude Code 现在会在任务失败、发现自身出错或用户报告问题时，自动起草反馈报告。用户可以在发送前审阅、修改并批准内容，也可以通过「/config」关闭或调整这一行为。

📎 多角度报道:

  • Claude Code可自动起草反馈，审核后发送 · Thariq (Twitter) · 反馈草稿工具说明

实践建议

  • 检查自动草稿是否包含复现步骤、期望行为、环境和关键上下文，再补充后提交。

  • 把反馈审阅纳入故障处理流程，记录报告质量和问题定位耗时。

7. Anthropic开放隐私保护的Claude使用数据供独立研究

  • 来源: Anthropic (Twitter)
  • 分类: 研究
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude AI影响 独立研究 隐私保护

摘要: Anthropic首次向外部研究人员开放经过隐私保护的真实Claude使用数据及研究工具，用于研究人工智能的实际影响。该计划旨在让相关研究不再只能在AI实验室内部进行，并承认单一公司无法完整呈现影响全貌。 斯坦福、牛津和 METR 三个研究团队设计了独立研究，分析 2026 年 4 至 5 月汇总的 25 万条 Claude 或 Claude Code 对话输出。研究分别关注人机协作、AI 使用感受和编程智能体带来的现实生产力，后续结果将进一步揭示 AI 的实际影响。 斯坦福 SALT Lab 对人们与 AI 协作的方式进行了研究，发现超过一半的对话涉及会影响他人或难以撤销的重大任务。该结果提示，AI 使用场景中需要更重视决策审查、责任边界和风险控制。 Anthropic 表示，Oxford 的 HIP Lab 正在研究 Claude 的行为与人们使用 AI 时主观感受之间的关系。METR 则在估计编程智能体带来的真实生产力提升，两项研究仍在进行中，后续将公布更多结果。 Anthropic 正在扩大面向研究者的研究合作模式，希望为当前工具难以支持的研究项目提供访问权限。研究者可以提交兴趣申请，说明希望借助这些工具推进的工作。

11. ChatGPT Work可代办登录型网页任务且不接触密码

  • 来源: Sam Altman (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: ChatGPT Work 浏览器操作 网页登录 智能体 隐私安全

摘要: ChatGPT Work现在可以通过电脑和浏览器登录网站执行任务，同时不直接看到用户的用户名或密码。用户可让它处理预约、账单、保险、房产和企业后台等操作型流程，但仍应审查关键提交和账户权限。

实践建议

  • 先用低风险、可撤销的预约或查询任务测试浏览器代办能力。
  • 为涉及支付、医疗和政府事务的流程设置人工确认，并逐项复核最终提交内容。
  • 使用专用账号和最小权限，避免把高敏感凭据或不必要的账户范围交给自动化流程。
