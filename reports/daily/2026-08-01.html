摘要: OpenAI Devs 宣布 GPT-5.4 和 GPT-5.4 mini 将于 8 月 31 日退出登录用户的 ChatGPT 模型列表，但仍可通过 API 和使用 API 密钥认证的 Codex 调用。与此同时，GPT-5.6 的 Luna 价格下调 80%、Terra 下调 20%，API 新增更快的 Sol 选项，降价也影响 Codex 和 ChatGPT Work 的用量计算。相关成本比较显示，模型单位价格和推理效率仍在快速改善，团队应在可用性、延迟、质量与渠道迁移之间重新评估选型。 OpenAI Devs补充介绍GPT-5.6的效率收益：Luna价格下调80%，Terra价格下调20%，API还新增更快的Sol选项。降价同时影响Codex和ChatGPT Work中的用量计算，使同等预算可以覆盖更多使用量。

  • 在 API、Codex 和 ChatGPT Work 中验证降价后的用量上限与输出一致性。

3. Qwen-Audio-3.0-ASR-Flash：上下文感知识别升级

  • 来源: Qwen (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Qwen-Audio 语音识别 专业术语 热词 结构化转录

摘要: Qwen发布Qwen-Audio-3.0-ASR-Flash，重点提升上下文一致性、专业术语识别和自定义热词能力，并支持将语音润色为结构化转录。内部测试中，医疗术语召回率为95.36%、工业术语召回率为93.24%；同时提供流式、文件和非实时接口。

实践建议

  • 用包含医疗或工业术语的真实音频测试术语召回率，并与当前ASR方案对比。
  • 根据实时、文件和非实时场景分别接入对应接口，评估延迟、成本与转录质量。
  • 为产品词汇配置自定义热词，检查其对专名识别和后续结构化处理的改善。

5. ChatGPT 工作入口升级：Activity + 个性化语音简报

  • 来源: OpenAI Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐ (3/5)
  • 标签: ChatGPT Activity视图 个性化 语音播客 项目管理 家庭日历

摘要: ChatGPT 桌面应用新增 Activity 视图，将需要用户关注的对话和项目近期更新集中展示，帮助用户从一个入口发现待处理事项。与此同时，ChatGPT 可以连接家庭日历并结合成员兴趣生成每日晨间播客，把多来源个人信息整理成持续更新的语音简报。两项体验都在强化 ChatGPT 作为长期上下文与日常任务入口的角色，但日历、家庭信息和项目权限仍应按成员分别配置。

📎 多角度报道:

  • ChatGPT可把家庭日程变成定制化晨间播客 · Sam Altman (Twitter) · 家庭播客用法

实践建议

  • 把持续运行的项目对话集中到项目空间，定期检查 Activity 视图中的待处理事项。
  • 连接日历与任务数据，先让模型生成每日简报提纲，再测试语音播报效果。
  • 为不同家庭成员设定兴趣与隐私边界，确认共享数据范围后再启用自动播报。
  • 为重要项目建立明确的跟进规则，减少遗漏新更新的风险。
