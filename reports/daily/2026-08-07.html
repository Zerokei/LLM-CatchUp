3. Codex Security Review进入研究预览

  • 来源: OpenAI Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Codex Security Review 代码安全 GitHub 自动审查

摘要: Codex Security Review进入研究预览，可结合代码仓库上下文深入检查GitHub拉取请求中的安全问题。它会直接在拉取请求中提供可执行的安全发现，并支持开启自动审查。

实践建议

  • 在隔离仓库开启自动审查，用包含依赖、权限和输入校验问题的拉取请求测试发现质量。
  • 将模型发现与人工安全审查和现有静态分析结果对比，再确定合并门禁规则。
