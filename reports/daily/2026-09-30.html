摘要: OpenAI 发布 GPT-6.1 Sol，面向编程、计算机操作和专业工作，官方称其智能水平接近 Astra。其 API 输入与输出 token 标准价格为 Astra 的五分之一。

实践建议

  • 选取真实编程与桌面操作任务，对比 Sol 和 Astra 的成功率、延迟及总 token 成本。
  • 核对当前 API 价格与任务质量后，再决定是否将高频专业工作迁移到 Sol。
