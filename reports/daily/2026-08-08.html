2. Claude Managed Agents更新：预算、仓库技能与顾问模型

  • 来源: Claude Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude Managed Agents 预算控制 仓库技能 顾问模型 Agent编排

摘要: Claude Managed Agents新增会话预算控制，达到上限后暂停并发出budget_reached事件，用户提高预算后可继续。它还可以在会话开始时从附加代码仓库的.claude/skills/目录自动加载技能，并为工作Agent配置更强的顾问模型提供第二意见。更新覆盖成本控制、技能复用和复杂任务复核三个层面，但自动加载的技能与顾问调用都应纳入版本、权限和成本治理。

📎 多角度报道:

  • Managed Agents可自动加载仓库中的技能 · Claude Devs (Twitter) · 仓库技能自动加载

实践建议

  • 为长期Agent会话设置预算上限并监听budget_reached事件，设计人工复核或调高预算流程。
  • 将审核过的通用技能放入.claude/skills/并纳入版本管理和代码审查。
  • 为高风险任务限定顾问模型调用条件，记录建议、执行结果和额外成本。

3. Claude Code更新：自动模式默认启用与跨会话协作

  • 来源: Claude Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude Code 自动模式 权限安全 会话消息 长时任务 管理员管控 Opus 5

摘要: Claude Code将从8月14日起对Pro、Max和Team用户默认启用自动模式，用独立分类器审查Shell命令和其他操作；测试中危险命令识别率为89%，对比手动审批的14%，分类器开销也不计入这些计划的用量限制。管理员可以通过托管设置固定默认模式或禁用自动模式，用户仍可切换模式，适合先在低风险、可回滚仓库中观察误拦截和漏检。与此同时，Claude Code新增跨会话消息，多个会话可以通过摘要交接、双向提问和状态同步并行处理任务，但接收会话不会自动获得原始历史或文件。该组合把长时任务的权限控制和多会话协作放进同一工作流，仍应以PR审查、CI和最小权限作为最终门禁。

📎 多角度报道:

  • Claude Code支持会话间互传任务 · Claude Devs (Twitter) · 会话摘要交接
  • 自动模式适合Claude Code长时任务 · Claude Devs (Twitter) · 长时任务与Opus 5
  • Claude Code将默认启用更安全的自动模式 · Thariq (Twitter) · 权限策略与安全动机
  • Claude Code自动模式将面向多类用户默认上线 · Thariq (Twitter) · 默认上线时间与测试数据

实践建议

  • 在默认切换前审查团队权限和生产仓库策略，先在隔离、可回滚的低风险项目启用自动模式。
  • 为自动模式保留管理员托管、命令审计和人工审批回退，并记录误拦截与漏检。
  • 用会话摘要拆分长任务，让一个会话实现、另一个会话审查或验证，并要求每个任务产出可审查PR和测试结果。
