**摘要**: Claude Code团队宣布，当前每周额度将先较现行水平减少17%，同时继续保留临时的50%提升。自9月14日起，Pro、Max、Team和席位制Enterprise套餐的标准每周额度将永久上调25%。团队表示还会加强用量可见性与控制，并邀请用户继续反馈以评估后续服务变化。 Claude Devs 说明，Claude Code 的每周额度相比当前水平将减少 17%。团队正在筹备相关变化，希望让用户获得更多使用感知，并提升用量可见性与控制能力。 Claude Devs 表示，团队正在调整 Claude Code 的服务方案，并计划让用户更清楚地了解和控制用量。官方同时邀请用户继续反馈并分享周末构建的项目。

> **实践建议**
> - 将9月14日标记为额度规则切换日期，记录近期高消耗任务并重新核对团队预算。
> - 在临时50%提升期间测试关键开发任务，评估永久25%提升后的容量是否足够。
> - 持续提交用量反馈，验证后续可见性与控制能力是否覆盖团队排期需求。
