1. DeepSeek-V4-Flash API 公测：适配 Codex

  • 来源: DeepSeek (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: DeepSeek-V4-Flash API Codex 模型接入

摘要: DeepSeek 宣布 V4-Flash API 开放公测，并提供与 Codex 的适配路径。后续说明确认 0731 版本主要更新 API，开发者应按接口能力和实际延迟评估迁移，而不要把 API 版本变化直接等同于模型权重变化。 DeepSeek 澄清，V4-Flash-0731 与预览版保持相同的模型架构和规模，本次升级仅适用于 DeepSeek-V4-Flash API。V4-Pro API 及 App、网页端模型暂未变化，官方表示 V4-Pro 正式版将随后发布。

实践建议

  • 用固定提示集对比 V4-Flash 与现有模型的质量、延迟和单位成本。
  • 先在 Codex 的非关键任务中灰度接入，确认兼容性、限流和数据策略。

  • 标签: GPT-5.6 API定价 推理优化 Fast模式 Codex ChatGPT Work 成本效率

摘要: GPT-5.6 系列通过推理栈、GPU kernel、推测解码和代理基础设施优化降低单位任务成本，并同步改善响应速度。更新覆盖 API、Codex 与 ChatGPT Work 等使用渠道，包含更快的 Fast 模式和新的价格方案。对需要持续运行代理或批量调用的团队而言，同一预算可以完成更多任务，但仍需用真实工作负载复核质量、延迟和配额差异。

8. Claude两起网络故障导致服务降级

  • 来源: Claude Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐ (3/5)
  • 标签: Claude 网络故障 服务可用性 流量重路由

摘要: Claude官方说明过去24小时发生两起事件，网络故障导致部分用户错误率上升或服务可用性下降。团队在流量重路由期间仍有请求失败，并正在恢复受影响的容量。 Claude Devs 说明两起网络事件曾导致服务降级，服务已恢复但容量仍在逐步回稳。依赖 Claude 的生产工作流需要把短时不可用、容量不足和恢复阶段的延迟波动分开监控。

实践建议

  • 为Claude调用增加超时、重试和跨供应商故障转移策略。
