1. Qwen3.8-27B登顶Harvey法律智能体基准

  • 来源: Qwen (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: Qwen3.8-27B 法律智能体 开源权重 基准评测

摘要: Qwen表示，Qwen3.8-27B 在 Harvey 的 Legal Agent 基准中成为开源权重模型第一名，并强调其规模适合在本地设备运行。引用的 ValsAI 数据显示，该模型以 11.3 分与 Fable 5 并列，并领先 Kimi K3、Qwen 3.8 Max 和 DeepSeek V4。

实践建议

  • 在本地环境部署 Qwen3.8-27B，使用法律文书抽取和检索任务做小规模评测。
  • 将 Legal Agent 类基准加入模型选型测试，比较本地模型与云端模型的准确率和成本。

2. Qwen3.8-27B登顶Cline本地模型榜

  • 来源: Qwen (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: Qwen3.8-27B Cline 本地模型 代码生成

摘要: Qwen宣布 Qwen3.8-27B 在 Cline 中成为排名第一的本地模型，上榜仅用四天。Cline 表示，这一结果终结了 Qwen2.5-Coder-7B 自四月以来持续四个月的领先记录。

实践建议

  • 在 Cline 中接入 Qwen3.8-27B，针对代码补全、重构和测试生成进行对比试用。
  • 记录本地推理延迟、显存占用与代码任务成功率，评估其替代小型云端模型的可行性。

3. GLM-5.3 API正式上线

  • 来源: Z.ai (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: GLM-5.3 API 代码生成 智能体 网络安全

摘要: Z.ai 宣布 GLM-5.3 API 已正式上线，定位于代码开发、防御性网络安全和长时程智能体任务。官方称其价格与 GLM-5.2 相同，可通过官方 API 及合作模型网关调用。

  • 对比 GLM-5.2 的价格、上下文处理和工具调用表现，再决定是否迁移现有调用。

4. Claude从零设计蛋白结合体命中14个靶点

  • 来源: Anthropic (Twitter)
  • 分类: 研究
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude 蛋白设计 从头设计 Adaptyv Bio Twist Bioscience

摘要: Anthropic测试Claude从零设计新型蛋白结合体，模型在15个目标中为14个目标设计出结合体候选。Adaptyv Bio和Twist Bioscience独立构建并测试了这些设计，用于验证模型输出能否进入真实实验环节。 在蛋白结合体设计实验中，Claude生成的设计成功结合的比例为22%至35%，而当前领域典型成功率约为10%至15%。其中部分设计的结合强度达到已发表从头设计结合体最佳水平的数倍。 Anthropic强调，高亲和力蛋白结合体不是药物，设计结合体只是开发类药分子的第一步。公司正在训练Claude覆盖从抗体到小分子等主要药物类型的完整开发流程，以扩大模型在生物医药中的作用范围。 Anthropic称，为科学家使用其最强模型建立访问计划仍是最高优先级之一，预计很快公布更多信息。官方同时表示，Opus 5目前仍是其面向生命科学研究可用的最强模型。 Anthropic表示，Claude如何执行蛋白设计实验及其完整结果已发布在官方博客中。该材料补充了实验流程和结果细节，使读者能够进一步核对模型输出与实际生物实验之间的关系。 Anthropic宣布发布一份关于Claude参与药物设计实验的技术报告，并同步开放相关提示词和数据。此举为外部研究者复现实验、检查方法边界和评估模型科学能力提供了基础材料。

5. Claude接入Gmail与Google Drive连接器

  • 来源: Claude (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude Gmail Google Drive 连接器

  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude Cowork 移动端 网页端 跨设备

摘要: Claude Cowork现已面向所有付费计划提供移动端和网页端访问，让用户可以在桌面发起任务后用手机继续查看结果。该能力此前从Max计划开始分阶段测试，后续逐步扩展到更多计划。

16. Asana 用 Codex 两周完成五年工程工作

  • 来源: OpenAI Blog
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐ (3/5)
  • 标签: Codex Asana 编码代理 遗留系统 软件测试

摘要: Asana 使用 OpenAI Codex 替换过时的测试系统，在两周内完成了原本预计需要五年的工程工作，成本约为 1.2 万美元。案例显示，编码代理在明确边界和可验证任务中可以显著压缩大型遗留系统改造的周期。
