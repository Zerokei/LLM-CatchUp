1. GLM-5.3 发布：编程与网络防御能力升级

  • 来源: Z.ai (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: GLM-5.3 开放模型 代理能力 网络安全 后训练

摘要: Z.ai 发布 GLM-5.3，主打编程和代理能力，并在 743B 基础模型上进行后训练。官方同时强调其网络安全防御能力在开放模型中实现明显跃升，相关技术博客已同步公开。 GLM-5.3 已通过 GLM Coding Plan 和 ZCode 提供使用，面向编程与代理开发场景开放。Z.ai 计划在完成严格安全评估后，分阶段推出 API 访问和开放权重。 Z.ai 称，GLM-5.3 将代理编程能力提升到新的水平，相比 GLM-5.2 有明显进步。模型在取得更好结果的同时减少了输出 token，意味着复杂编码任务可能获得更低的推理成本。 Z.ai 表示，首批合作伙伴已经通过官方服务提供 GLM-5.3 驱动的产品与服务。合作伙伴接入遵循统一的安全防护和使用政策，后续将以公开方式扩大接入范围并发布进展。

实践建议

  • 将 GLM-5.3 放入隔离环境，分别测试代码代理、漏洞分析和防御任务。
  • 结合技术博客核对模型的训练边界、评测方法与安全限制，再安排生产试用。

2. Grok 4.6 登陆 Pi，面向长时 Agent 任务

  • 来源: xAI (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: Grok 4.6 Pi Agent 模型定价

摘要: Grok 4.6 已在 Pi 上线，定位于长时间运行的 Agent 任务，并强化编码、知识工作和视觉任务能力。相关信息给出的价格为每百万输入 token 2 美元、每百万输出 token 6 美元。

实践建议

  • 用一组需要持续多步执行的编码或知识工作任务测试 Grok 4.6 的稳定性。
  • 按输入和输出 token 分开记录成本，再与现有 Agent 模型比较。

3. Gemini 3.7 Flash 发布：编码与知识工作全面提速

  • 来源: Google DeepMind (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: Gemini 3.7 Flash 代码生成 网页开发 知识工作 模型发布

摘要: Gemini 3.7 Flash 面向编码、网页开发和知识工作带来新一轮能力提升。更新重点包括更强的调试与问题解决、更少提示词完成网页构建，以及更快的整体响应。产品同时强调更低的入门价格，便于开发者和团队扩大使用。 Google DeepMind 表示，Gemini 3.7 Flash 在调试和问题解决等编码任务上较 3.6 Flash 有明显提升，也能用更少提示词设计更实用的网页布局和应用。它还强化了现实业务工作流中的推理与准确性，可在 Antigravity、Google AI Studio、Android Studio 及 Gemini Spark 中使用。

4. DeepSeek V4 Pro 发布，支持弹性推理与 Responses API

  • 来源: DeepSeek (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: DeepSeek V4 Pro Agent 弹性推理 Responses API Codex

摘要: DeepSeek 发布 V4 Pro，主打 Agent 能力和生产任务表现提升，并为 V4 Pro 与 V4 Flash 提供从低到高的弹性推理强度。模型支持原生 OpenAI Responses API，已在应用、网页和 API 中提供，网页端可通过 Expert Mode 使用。 随着 V4 系列发布，DeepSeek 更新 API 价格并引入高峰与非高峰时段费率。非高峰价格比高峰低 50%，新价格将于 2026 年 8 月 16 日 16:00 UTC 起生效。

  • 通过 Responses API 做一条兼容性验证链，重点检查工具调用和 Codex 接入。
  • 记录 Expert Mode、API 与网页端在同一任务上的成本和成功率。

6. Claude Code 新增用量重置后自动续跑

  • 来源: Claude Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude Code 桌面端 自动续跑 用量限制

摘要: Claude Code 桌面端新增自动继续选项，用户达到用量上限后可以开启自动续跑。额度重置后，工具会从中断处继续工作，减少长任务因限额被迫暂停的情况。

7. ChatGPT Computer History：跨应用工作记忆正式推出

  • 来源: OpenAI (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Computer History ChatGPT Codex 工作记忆 隐私控制

摘要: Computer History 让 ChatGPT 和 Codex 在用户授权后理解近期电脑活动，减少重复解释并延续工作上下文。新时间线帮助用户回看工作记录，同时加入更细的隐私控制与设置入口。功能正在面向桌面端的 Pro、Business 和 Enterprise 用户全球推出，部分地区分阶段开放。 Computer History 在 Chronicle 研究预览基础上降低了令牌消耗，并加入新的时间线视图。用户可以回看工作记录、清除全部或部分历史、选择是否包含特定应用和网站，也能随时暂停或恢复记录。 ChatGPT 桌面端 Mac 版开始向 Pro、Business 和 Enterprise 用户全球推出 Computer History。该功能需要在设置的集成选项中主动开启，欧洲经济区、英国和瑞士的用户将在后续几周获得访问权限。

8. OpenAI 预览 GPT-5.6 Sol 的 Ultrafast 模式

  • 来源: OpenAI (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: GPT-5.6 Sol Ultrafast OpenAI API 模型推理

摘要: OpenAI 正预览 Ultrafast 模式，让 GPT-5.6 Sol 的速度最高提升至原来的 14 倍。该能力首先在 OpenAI API 中向一批精选客户开放，随着容量增加会逐步扩大到更多企业。 OpenAI 表示 Ultrafast 由 Cerebras 提供支持，最高可生成每秒 750 个令牌。该模式面向实时语音、客服、商业、代码与设计、金融研究和安全响应等需要高速前沿智能的企业工作流。 OpenAI 正与首批客户合作，评估 Ultrafast 高速推理在哪些业务场景中最能产生差异。企业如果需要更快的前沿智能，可以登记通知，在容量扩大后获得进一步访问机会。

📎 多角度报道:

  • Sam Altman 转发 OpenAI GPT-5.6 Ultrafast 预览 · Sam Altman (Twitter) · 官方转发与市场关注

实践建议

  • 用固定任务集测量高速模式对延迟、吞吐和输出质量的影响。
  • 为逐步扩大的 API 访问准备限流、成本上限和回退模型策略。

9. Google Sheets Canvas：用提示词把表格变成互动看板

  • 来源: Google AI Blog
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Google Sheets Sheets Canvas 数据可视化 提示词

摘要: Sheets canvas 允许用户通过简单提示词，把表格数据转换为互动式仪表盘、学习追踪器和座位图等成果。它将数据整理与定制化展示结合起来，降低了从表格生成可视化工具的门槛。

实践建议

  • 选一份真实运营表格，用提示词生成看板并核对关键指标是否准确。
  • 为生成的学习追踪器或座位图建立人工复核步骤，避免源数据错误直接进入展示结果。

11. Google DeepMind 发布 SL2T：手语直译文字登陆 Android

  • 来源: Demis Hassabis (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: SL2T 手语识别 Android 无障碍 Google DeepMind
