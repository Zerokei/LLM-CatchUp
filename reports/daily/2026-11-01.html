1. Karpathy用Claude打造HackerTube视频推荐站

  • 分类: 教程与观点
  • 重要性: ⭐⭐⭐ (3/5)
  • 标签: Claude Code Opus 5.5 AI编程 推荐系统 个人项目

摘要: Karpathy分享周末项目 HackerTube：他让 Claude 从 Hacker News 二十年间约4300万条评论中筛出反复被推荐的视频，形成约6454条视频列表，称体验明显优于 YouTube 推荐。项目还提供基于视频中段画面的缩略图、无需登录的本地浏览状态及可供 Claude 二次开发的数据包；从开发到部署主要由 Claude Code 和 Opus 5.5 完成。
