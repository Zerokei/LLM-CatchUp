2. Codex 与 ChatGPT Work 支持只读共享线程

  • 来源: OpenAI Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Codex ChatGPT Work 只读链接 项目交接

摘要: Codex 和 ChatGPT Work 现在可以把共享线程发布为只读链接，让协作者看到构建过程背后的上下文与推理。它覆盖 Pull Request、技术深潜和项目交接等场景，有助于让工作过程更容易复盘和传递。 Codex 和 ChatGPT Work 的共享线程支持生成只读链接，让他人直接查看构建过程、上下文和推理过程。该功能适合分享 Pull Request、深度分析或项目交接，减少依赖截图还原工作背景的成本。

实践建议

  • 在交付代码时附上只读线程链接，让评审者直接了解实现过程。
  • 将深度分析线程作为项目文档入口，减少重复解释背景。

3. Claude 平台开放代理工具链：浏览器、Skills 与 Files API

  • 来源: Claude Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Claude Platform Computer Use 浏览器自动化 Skills API Files API 托管代理 AG-UI

摘要: Claude 平台现已开放 Computer Use、浏览器工具、Skills API 和 Files API，开发者可以自动化没有 API 的应用并构建托管代理。计算机操作支持单轮连续执行多步动作，早期客户的任务往返次数减少了 20% 至 40%；浏览器工具还提供页面结构引用，降低布局变化对自动化的影响。Skills 可以版本化团队流程，Files 支持复用文件、设置过期时间，并提供更高的速率和组织级存储配额。托管代理也可通过 AG-UI 适配器接入聊天界面，流式传递文本、工具调用和思考状态。 Claude的计算机操作工具现在可以在一次交互轮次中连续执行点击、输入、按键和截图等多个动作，不必每一步都等待往返。早期客户的任务往返次数减少了20%至40%，有望缩短执行时间并降低成本。 browser_toolset_20260801为Claude提供页面结构信息，使浏览器自动化可以使用元素引用和坐标，而不再依赖易受布局变化影响的纯像素定位。这样能提高页面轻微改版后的自动化稳定性。 Skills API和Files API被定位为Claude Managed Agents的基础构件。团队可以上传并版本化操作流程，再通过version_id或latest将指定版本绑定到请求中，从而让代理行为更可控、更易回滚。 Files API支持上传一次后通过file_id在多次请求中复用文件。此次更新增加expires_in_seconds过期控制，将速率上限提高到每分钟500次，并把单组织存储容量提升到1TB。

实践建议

  • 选择一个没有 API 的内部流程进行小规模 Computer Use 试点，先限制权限和操作范围。
  • 把稳定的团队 SOP 封装为可版本化 Skill，并在生产请求中固定 version_id。
  • 为重复使用的参考资料保存 file_id，按敏感度设置过期时间。
  • 在聊天界面展示工具调用和人工接管点，记录代理失败原因与恢复路径。

6. Muse Spark 1.2：从视觉推理到机器人行动

  • 来源: Meta AI (Twitter)
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: Muse Spark 1.2 多模态模型 视觉推理 代码生成 机器人 工具调用 WildArtifactBench

摘要: Muse Spark 1.2 覆盖从图像或视频生成网页、游戏等数字产物，到音视频理解、视觉推理和工具使用的多模态任务。模型会检查视觉输入并把观察结果纳入后续推理，还能为机器人编排子任务、解析工具调用并根据结果循环执行。相关能力已延伸到媒体生成和训练数据描述，展示了从感知到可运行产物与物理行动的连续链路。配套的 WildArtifactBench 用真实复杂任务、多种交付格式以及人类与智能体偏好产生的胜率和 Elo 评估这类代理能力。 Meta AI 将通过一组新评测展示 Muse Spark 1.2 在视觉推理、图表理解和知识密集型任务上的表现。该条内容预告了模型能力评估的范围，但没有给出具体分数。 Meta AI 表示，Muse Spark 1.2 在工具使用场景中的推理能力有所增强。模型会更细致地检查视觉输入，并把观察结果纳入后续推理过程。 Muse Spark 1.2 可以直接从图像或视频生成网页、游戏等数字产物，把视觉布局、层级和风格转换为可运行代码。模型还会依据实际渲染和行为检查正确性，并通过持续自我改进循环优化输出。 Muse Spark 1.2 的机器人变体可以充当任务编排器，接收用户指令、解析工具调用、观察结果并循环执行。演示中，模型为双臂机器人规划整理桌面的子任务，并区分相似物品后完成收纳。 Meta AI 表示，Muse Spark 已在媒体生成等多个内部场景部署，并可为 Muse Image 和 Muse Video 生成详细描述作为训练数据。模型还能够把文本、图像和视频转换为下游应用可用的信号与洞察。

  • WildArtifactBench 开放十项智能体任务 · Meta AI (Twitter) · WildArtifactBench 评测与样例

实践建议

  • 用固定网页截图测试模型生成代码的视觉还原度与交互完整性。
  • 在模拟环境中测试从视觉观察、任务规划到机器人执行的闭环。
  • 建立包含图表理解、知识密集任务和多种交付物的评测样例集。
  • 分别记录代码生成、音视频理解和物理行动三个环节的失败率。
