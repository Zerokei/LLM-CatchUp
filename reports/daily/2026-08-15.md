### 2. [Claude Code Auto mode 成为默认权限模式](https://x.com/ClaudeDevs/status/2088332927189049738)

- **来源**: Claude Devs (Twitter)
- **分类**: 产品与功能
- **重要性**: ⭐⭐⭐⭐ (4/5)
- **标签**: `Claude Code` `Auto mode` `权限模式` `Shell 安全`

**摘要**: Claude Code 的 Auto mode 面向 Pro、Max 和 Team 用户逐步成为默认权限模式，并允许通过 Shift+Tab 随时切换或用 defaultMode 固定模式。该模式使用独立分类器审查 shell 命令和操作，测试中识别出 89% 的危险命令，而手动审批识别率为 14%。 Claude Code 提供 auto-mode-setup 命令，会检查代码仓库并建议可供审核的可信仓库和域名。配置中提供的信息越完整，系统越容易明确哪些操作可以安全执行。

> **实践建议**
> - 在非生产仓库开启 Auto mode，记录分类器对常用命令的放行和拦截结果。
> - 为团队保留 Shift+Tab 手动切换路径，并为高风险操作制定人工复核规则。
