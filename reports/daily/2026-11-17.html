1. GPT-6.2 Astra与Sol发布，兼顾专业能力与效率

  • 来源: OpenAI Blog
  • 分类: 模型发布
  • 重要性: ⭐⭐⭐⭐⭐ (5/5)
  • 标签: 旗舰模型 专业工作流 智能体编程 词元效率 极速推理 接口价格 模型安全

摘要: OpenAI发布面向复杂专业工作的GPT-6.2 Astra和面向日常任务的Sol，强化文档、编码与计算机操作能力，并减少任务所需的输出词元。官方称Astra在长流程专业任务和科学评测中取得提升，其API输入与输出单价较GPT-6 Astra降低20%，Sol延续上一代单价。两款模型已进入ChatGPT Work、Codex和API，Sol的Ultrafast模式扩展至Pro 200套餐。发布也加强了对高风险网络安全及生物化学请求的防护。

实践建议

  • 用同一组文档、编码和科学任务对比Astra与Sol的完成质量、延迟和单任务成本。
  • API迁移时保留稳定提示词前缀，检查缓存命中和实际词元消耗。
  • 在支持的套餐中对比Sol标准模式与Ultrafast的响应速度和额度消耗。

摘要: Gemini 4 Hydrogen于11月12日发布，定位快速编码、多模态综合与日常工作流，官方称其任务速度为3.8 Flash的2.5倍，并在Artificial Analysis智能指数上超过Argon。发布信息覆盖AI Studio、Gemini API、企业版、应用和搜索等入口。本次快照中的11月17日更新展示了Antigravity机器人插件，可连接受支持的机械臂，先在MuJoCo中练习，再以对话执行真实任务。同日另一演示通过Antigravity将数千个Google Sheets单元格变为像素动画画布。

3. OpenAI披露AI芯片设计与RISC-V优化成果

  • 来源: OpenAI Blog
  • 分类: 研究
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: 芯片设计 硬件优化 处理器架构 电子设计自动化 实证评测

摘要: OpenAI称，模型提出的改进已在Jalapeño芯片上验证，向量单元与矩阵单元的标准单元面积分别减少约13%和10%，与AMD合作的旗舰GPU模块功耗、性能和面积指标相对优化基线最高改善14%。在两款开源RISC-V内核的评测中，GPT-6.2 Astra表现领先，公司还将与Synopsys训练面向EDA工具的GPT-Synopsys。

4. Claude Code 试验脚本串联工具的 Code Mode

  • 来源: Claude Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: 代码模式 工具编排 异步交互

摘要: Claude Code 推出实验性 Code Mode，让 Claude 编写脚本，将多个工具调用串联成更复杂的工作流程。长时间命令仍在运行时，它也能继续回答用户；可通过环境变量 CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1 选择启用。

实践建议

  • 在测试项目中设置 CLAUDE_CODE_EXPERIMENTAL_CODE_MODE=1，比较多工具任务的执行流程。
  • 运行一个耗时命令并继续提问，验证并行交互和结果回收是否符合预期。

5. Gemini任务向六国免费开放，扩展代办与支付

  • 来源: Google AI Blog
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: 任务助手 代理支付 个人助理 应用连接 权限控制

摘要: Google将基于Gemini 4 Hydrogen的任务功能免费推向美国、日本、韩国、加拿大、澳大利亚和印度，进阶功能先从美国上线。新增能力结合电话、邮件、短信、密码管理和Google Pay，可完成预约、账单分析与购物等任务，并通过隔离虚拟机、反注入防护及关键步骤确认控制风险。

实践建议

  • 在支持地区从Gemini首页切换到任务模式，用预约或整理日历等低风险任务评估完成率。
  • 尝试购物任务前设定明确消费上限，并检查支付及第三方应用授权。
  • 对未完成的网站步骤保留人工接手流程，并反馈失败原因。

6. ChatGPT for Sales整合销售插件与客户流程

  • 来源: OpenAI Blog
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐⭐ (4/5)
  • 标签: 销售助手 插件生态 客户关系管理 商机跟进 企业工作流

摘要: OpenAI推出ChatGPT for Sales，提供新的Sales插件及30多个新增或增强的合作伙伴插件，将客户研究、销售材料、会议准备和后续跟进集中到对话中。该产品可结合CRM、客户通话、商机数据及报价工具整理上下文，也支持由dot持续检查交易变化并准备待审核的下一步。

实践建议

  • 选择一个商机，连接已获授权的CRM与会议资料，核对自动生成的会议简报和跟进草稿。
  • 让工作区管理员先确认Sales及所需合作插件的可用范围和操作权限。

8. OpenAI API 用量面板新增限流与错误分析

  • 来源: OpenAI Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐ (3/5)
  • 标签: 用量监控 成本分析 限流排查 错误诊断

摘要: OpenAI 更新 API 用量面板，支持更方便地跟踪用量与支出，并查看速率限制及被限流的请求。开发者还可按模型、项目或 API 密钥分析错误，定位调用问题。

9. Claude 平台测试第三方工具关联计费

  • 来源: Claude Devs (Twitter)
  • 分类: 产品与功能
  • 重要性: ⭐⭐⭐ (3/5)
  • 标签: 关联计费 接口管理 企业集成

摘要: Claude Platform 开始测试关联计费，Factory、Linear 和 Ramp 等工具的用户可通过自己的 Claude 平台组织支付 API 用量费用。此方式无需向这些工具共享 API 密钥。

实践建议

  • 在已支持的第三方工具中检查关联计费入口，并核对费用归属的 Claude 平台组织。
  • 试用后核对平台账单中的 API 用量，确认工具侧用量与组织支出一致。
