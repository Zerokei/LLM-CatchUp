### 1. [DeepSeek V4 Flash Vision Experimental 上线](https://x.com/deepseek_ai/status/2090730032574631962)

- **来源**: DeepSeek (Twitter)
- **分类**: 模型发布
- **重要性**: ⭐⭐⭐⭐⭐ (5/5)
- **标签**: `DeepSeek V4` `V4 Flash Vision` `多模态代理` `模型发布` `DeepSeek Harness`

**摘要**: DeepSeek V4 Flash Vision Experimental 已在 DeepSeek API 平台上线，文本能力对齐 V4 Flash，并覆盖代理、推理和世界知识任务。官方还称其在多模态代理基准上较 V4 Flash 有明显提升，表现接近 Opus 4.8，并同步发布 DeepSeek Harness 0.1.1 的原生支持。 DeepSeek 表示，V4-Flash-Vision-Exp 可以在多种代理框架中结合视觉理解与工具调用。其目标是把图像理解能力融入更广泛的代理工作流，支持处理现实任务中的视觉信息与工具操作。 DeepSeek V4 Flash Vision Experimental 支持在 API 中处理图像输入，并可通过 Chat Completions、Messages 和 Responses 接口调用。图片可以使用 Base64、外部 URL 或 Files API 提供，且每张图片最多按 384 个 token 计费。 DeepSeek Files API 已上线并免费提供，用户可以上传图片后通过 file_id 在后续请求中重复引用。该机制避免同一图片反复上传，有助于减少请求带宽并简化多轮视觉应用的文件管理。

> **实践建议**
> - 在 DeepSeek API 中用 model='deepseek-v4-flash-vision-exp' 跑一组图像代理任务。
> - 用 DeepSeek Harness 0.1.1 复现多模态代理基准，并与 V4 Flash 做成本和效果对比。

### 2. [Claude Code Remote Control 聚焦可靠性改进](https://x.com/ClaudeDevs/status/2090933155847143498)

- **来源**: Claude Devs (Twitter)
- **分类**: 产品与功能
- **重要性**: ⭐⭐⭐⭐ (4/5)
- **标签**: `Claude Code` `Remote Control` `可靠性` `远程开发`

**摘要**: Claude Devs 表示，团队根据用户反馈持续修复 Remote Control 的可靠性问题。此次更新围绕远程控制体验展开，但该条信息本身未列出具体改进项目。 Claude Code 现在支持直接从手机启动远程会话。开启 `claude remote-control` 的电脑会以设备卡片显示在 Code 标签页顶部，用户选择目录后即可让会话在该电脑上启动。 Claude Code Remote Control 现在会让手机端持续跟随电脑上正在运行的会话。用户在笔记本上恢复会话后，手机不会再把它归档；电脑端退出后，手机也会在数秒内显示离线，减少过期状态。 Claude Code 现在能在连接短暂中断后自动恢复会话。用户关闭笔记本或切换 Wi-Fi 后，无需手动重连即可继续使用原有开发会话。 Claude Code 的手机端和 CLI 会话现在可以同步模型与 effort level，iOS 打开大型会话的速度也更快。移动端的 `/clear`、`/compact` 和 `/diff` 斜杠命令得到改进，分别用于重置视图、显示压缩标记和打开原生差异面板。 Claude Devs 表示 Remote Control 还会继续改进，并建议用户把 CLI、桌面端和移动端更新到最新版本并开启自动更新。相关功能和使用方式已在 Claude Code 文档中同步说明。

> **实践建议**
> - 在真实网络环境下连续测试远程会话的启动、恢复和退出流程，记录状态不同步的场景。
> - 将 Remote Control 的连接稳定性纳入团队开发工具评估与回归测试。

**摘要**: Claude Security 扫描现已运行在 Claude Mythos 5 上，并向所有 Claude Enterprise 客户开放公测。企业无需单独申请或管理模型访问权限，就能让最强安全模型扫描自己的代码库。 用户可以把 GitHub 仓库交给 Claude Security 扫描，Mythos 会跨文件追踪数据流并推理组件之间的交互。每个发现都会附带 CWE 分类、置信度和严重性评级，以及一条建议修复方案。 Claude Security 的扫描结果现在可以在 Claude Code 网页端打开建议补丁，并继续使用团队已有的模型。模型在扫描后台运行，只返回发现结果和修复建议，不要求用户直接访问 Mythos 5；扫描按现有套餐的标准 Token 用量计费。 Claude Security 正在把 Mythos 5 集成到合作伙伴的安全产品和服务中，让更多防御方获得前沿模型能力。Anthropic 同时设立 3500 万美元的 Defender Advantage Fund，为开源安全项目提供额度，并将扩大 Cyber Verification Program。

> **实践建议**
> - 在 Enterprise 账户中启用公测，对一组代表性仓库建立基线扫描。
> - 比较 Mythos 5 扫描结果与现有 SAST 工具，确定互补的安全门禁。
